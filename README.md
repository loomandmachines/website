# Loom & Machines

Branding, film, AI and engineering, from Kochi, India.

This repository is our website: one hand-built page in plain HTML, CSS and a few lines of JavaScript. No framework, no page builder, no template.

## What's here

- `index.html` – the page
- `styles.css` – layout and type
- `script.js` – the phone menu
- `images/` – photographs and the branding reel

## Run it locally

Open `index.html` in a browser. That's it.
